# «Жар» — Telegram Mini App для заказа еды

Приложение внутри Telegram для бургерной: меню с категориями, корзина, оформление доставки или самовывоза. Заказ приходит сотрудникам в Telegram, они меняют статус кнопками, а клиент получает уведомления.

> Демо-проект для портфолио. Заведение вымышленное.

## Как это работает

```
Клиент → «🍔 Открыть меню» → Mini App (корзина, оформление)
       → заказ уходит боту → бот пересчитывает сумму по своему меню
       → сотрудник получает заказ: [Принять] [Передан курьеру] [Выполнен] [Отменить]
       → клиент получает уведомление на каждом шаге
```

## Возможности

**Mini App**
- Меню по категориям, закреплённая лента категорий с подсветкой при прокрутке
- Корзина с изменением количества, сохраняется при закрытии приложения
- Доставка или самовывоз, расчёт стоимости доставки и подсказка «добавьте ещё на N ₽ — доставка будет бесплатной»
- Минимальная сумма заказа, выбор времени, способ оплаты, комментарий
- Телефон и адрес запоминаются для следующего заказа
- Нативные элементы Telegram: главная кнопка (MainButton), кнопка «Назад», вибрация, цвета темы пользователя
- Работает и в обычном браузере (демо-режим) — удобно показывать заказчику

**Бот**
- Приём заказа и **пересчёт суммы на сервере**: цены из приложения не учитываются, поэтому подделать сумму нельзя
- Проверка состава, количества, адреса, телефона и минимальной суммы
- Статусы: Новый → Готовим → В пути / Готов к выдаче → Выполнен (или Отменён)
- Кнопки для сотрудников, защита от недопустимых переходов и нажатий посторонних
- «Мои заказы» для клиента
- 10 автотестов, включая полный путь заказа

## Стек

**Mini App:** HTML, CSS, JavaScript, Telegram WebApp API
**Бот:** Python 3.13, aiogram 3, SQLite

## Структура

```
webapp/
  index.html, css/, js/app.js — приложение
  menu.json                   — меню (его же читает бот)
bot/
  __main__.py                 — запуск
  handlers.py                 — команды, приём заказов, статусы
  orders.py                   — проверка и пересчёт заказа
  storage.py                  — база заказов
tests/                        — автотесты
```

Чтобы адаптировать проект под другое заведение, достаточно поменять `webapp/menu.json`.

## Запуск

### 1. Опубликовать Mini App
Telegram открывает Mini App только по HTTPS. Самый простой путь — **GitHub Pages**:
1. Загрузите проект в репозиторий на GitHub.
2. *Settings → Pages* → ветка `main`, папка `/ (root)`.
3. Приложение будет доступно по адресу вида `https://ваш-ник.github.io/cafe-miniapp/webapp/`.

### 2. Запустить бота
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # впишите BOT_TOKEN, WEBAPP_URL и ADMIN_IDS
python -m bot
```

Откройте бота в Telegram, нажмите /start, затем «🍔 Открыть меню».

### Посмотреть приложение без Telegram
```bash
python -m http.server 5600 --directory webapp
```
и откройте http://localhost:5600.
